問題介紹3 / 18

0/1 的意義

對每件物品，我們只有兩種決定：

  • Xi = 0：不放入物品 i
  • Xi = 1：放入物品 i

物品不能分割，因此 Xi 不能是 0.5 或其他分數。

最大化
Σ piXi
限制
Σ wiXi ≤ 8
Xi ∈ {0, 1}

例如一台果汁機只能整台帶走，不能只帶走半台。

動態規劃思路5 / 18

動態規劃的核心

動態規劃把原問題拆成較小的問題，並保存已經算過的最佳答案。

選項一

不放入目前物品，沿用先前的最佳結果。

選項二

放入目前物品，將剩餘容量的最佳結果加上目前利潤。

每個狀態都比較「不放」與「放入」，保留利潤較大的結果。

表格法8 / 18

狀態轉移公式

V(i,w) = max{ V(i−1,w), V(i−1,w−wi) + pi }

不放物品 i

使用 V(i−1,w)，直接沿用上一列同一容量的最佳結果。

放入物品 i

使用 V(i−1,w−wi) + pi，把剩餘容量的結果加上目前利潤。

若 wi > w，物品放不進去，因此 V(i,w) = V(i−1,w)。

表格法14 / 18

回溯選擇的物品

  1. V(4,8) = 8，與上一列同欄的 7 不同，因此選擇物品 4。
  2. 剩餘容量為 8 − 5 = 3。
  3. V(3,3) 與 V(2,3) 相同，因此不選物品 3。
  4. V(2,3) 與 V(1,3) 不同，因此選擇物品 2。
答案：(X₁, X₂, X₃, X₄) = (0, 1, 0, 1)
總重量 = 3 + 5 = 8　最大利潤 = 2 + 6 = 8

集合法16 / 18

容量限制與支配規則

容量限制

重量超過 8 的有序對直接刪除。

例如：(8,9)

支配規則

若狀態 A 的重量不大於狀態 B，而且利潤不小於狀態 B，則 A 支配 B。

(5,4) 支配 (3,5)

(5,4) 的利潤較高、重量較小，因此可以刪除 (3,5)。

動畫範例：將有序對放在重量與利潤平面上，被支配的點逐漸淡出。
